# PhysioQR Frontend

React + TypeScript + Vite frontend for the PhysioQR rehabilitation and doctor-referral platform.

## Stack

- React 18
- TypeScript
- Vite
- React Router
- TanStack Query
- Axios
- Tailwind CSS
- React Hook Form + Zod
- Vitest + Testing Library

## Run Locally

```powershell
npm install
npm run dev
```

Vite will print the local development URL in the terminal.

## Quality Checks

```powershell
npm run lint
npm run build
npm test -- --run
```

## Source Structure

```text
src/
├── app/          # providers, guards, router and role route modules
├── components/   # reusable UI/data-display/feedback components
├── features/     # feature and role-owned application code
├── layouts/      # role/public layouts
├── lib/          # shared infrastructure and utilities
├── stores/       # application state
├── styles/       # global styles/design system
└── types/        # shared TypeScript types
```

Role-specific functionality belongs inside its feature (`admin`, `agents`, `doctors`, `patients`). Keep globally shared components generic and reusable.

## Build

```powershell
npm run build
```

Production output is generated by Vite in `dist/`.
