# Admin Panel Integration Brief

Objective: Convert the PhysioQR admin panel from mock-only management pages to production-style API-backed admin operations where backend endpoints already exist.

Target audience: Admin operators managing a healthcare rehabilitation SaaS: doctors, agents, patients, programs, exercises/videos, payments, refunds, withdrawals, fraud, support, audit logs, notifications, and settings.

Aesthetic direction: Quiet operational SaaS UI. Dense but readable tables, compact filters, clear status badges, no marketing hero layout, no decorative excess.

Existing frontend stack:
- React + TypeScript + Vite
- Tailwind CSS
- React Query
- Axios API client at `physioqr/src/lib/api-client.ts`
- Layout/routing in `physioqr/src/app/router.tsx`
- Admin pages in `physioqr/src/features/admin/pages`
- Shared components in `physioqr/src/components`

Existing backend base:
- Backend API base is `/api`
- Admin endpoints include `/admin/dashboard`, `/admin/agents`, `/admin/doctors`, `/admin/patients`, `/admin/payments`, `/admin/orders`, `/admin/withdrawals`, `/admin/wallets`, `/admin/fee-shares`, `/admin/risk-reviews`, `/admin/fraud-cases`, `/admin/audit-logs`, `/admin/content-summary`
- Module endpoints include `/programs`, `/exercises`, `/refunds`, `/notifications`, `/support`, `/settings`

Primary task:
- Work in `physioqr/src/features/admin/pages/AdminOperationsPages.tsx` and adjacent admin frontend files only if needed.
- Replace mock-only operation rows for supported modules with API-backed data loading using `apiClient` and `useQuery`.
- Preserve existing visual language and responsive behavior.
- Add loading and error states using existing components.
- Keep mock fallback only for modules where no backend endpoint exists yet.
- Do not rewrite the whole admin panel or landing page.
- Avoid unrelated styling churn.

Important modules to prioritize:
- Programs
- Exercises/videos
- Orders
- Refunds
- Fee shares
- Wallets
- Payouts/withdrawals
- Notifications
- Support
- Fraud risk
- Audit logs
- Risk reviews
